# BKESIT Software Catalogs

Public, GitHub-native distribution repository for approved ProjectFreedom / BKE Digital Solutions software releases.

- Source, builds and certification remain in their individual ProjectFreedom engineering repositories.
- BKESIT owns customer-facing release publication. Software license/activation rights remain with BKE Licensing.
- Release files are distributed using GitHub Releases; images and catalog manifests are GitHub-backed. No S3/R2/upload service is required for catalog assets.
- Never publish draft, prerelease, or uncertified source products. Validate exact source tag, commit, size and SHA-256 before publishing.
- A GitHub Release does not grant entitlement; license activation is enforced separately.

Publishing must be deliberate and traceable to a certified source release. No customer-facing binaries are published by initial repository setup.
